# Yururi Reader — feedback

This repository is a place to report problems and ask for changes.
**There is no source code here**, and none will be published.

- 📱 Get the app: <https://play.google.com/store/apps/details?id=chat.gptalk.app.readulo>
- 🌐 Website: <https://yururi.zlogic.run>

用中文或 English 都可以。这个仓库只用来收反馈，不含源码。

## What to use it for

- Something in the app is broken — a crash, text that will not lay out, a book that
  will not open, audio that stops mid-sentence
- Something behaves differently than the description promises
- Feature requests

## What not to use it for

- **Do not attach copyrighted books.** A few words identifying the file (format,
  file size, where you got it) is enough to reproduce a bug. Do not upload the EPUB
  or PDF itself.
- Do not report Play Store issues — reviews, refunds, install failures, anything
  about your account. Those go through Google, and we cannot see them:
  <https://support.google.com/googleplay/android-developer/contactus>

## Before you file a bug

1. Check the [open issues](https://github.com/zlogic-labs/yururi-feedback/issues) —
   it may already be known.
2. Note the **exact file format** (EPUB / EPUB3 / PDF / TXT / MOBI / AZW3) and, for
  PDFs, whether it is text-based or a scan.
3. If it is a scanned PDF, say so. Text recognition is a separate code path and its
  failures look nothing like ordinary layout bugs.
